# HTML5 Semantic Structure & Accessibility Portfolio Website

## Project Overview

This project is a multi-page personal portfolio website built using modern semantic HTML5 elements and accessibility best practices. The website follows WCAG guidelines and includes SEO-friendly metadata, responsive design, and keyboard-accessible navigation.

---

## Features

* Semantic HTML5 structure
* WCAG accessibility support
* ARIA labels and roles
* SEO-friendly meta tags
* Responsive design
* Keyboard tab navigation
* Accessible contact form
* Mobile-friendly layout

---

## Technologies Used

* HTML5
* CSS3
